背景：报告 V0.4.1 §13.2 局限 #3（E3 激活与初始化耦合比较）与 #5（组件组合非完整因子实验，E3/E4/E5 冻结对照结构为 [128] 而最终模型为 [256]）为已披露局限。E7 的目的是在训练开始前补足这两项：把 E3/E4/E5 的预注册协议原样搬到 [256]，并补一组激活×初始化完整因子对照。E7 全部为 validation-only，**不改变 E6 选型、不触碰封存测试集、不替换已交付最终模型**。

2. 研究问题

- Q1（复验）：在 [256] 架构上，E3（激活）、E4（L2）、E5（训练策略）的组间排序是否与 [128] 上的冻结结论一致？
- Q2（解耦）：把激活函数与初始化策略解耦为完整因子对照后，E3 的耦合结论（ReLU+auto 最优）是否成立？差异主要由激活、初始化还是两者交互贡献？

4. Block 设计（新运行 39 次；复用 3 次已冻结运行）

- **E7-A 激活复验（[256]，E3 协议）**：{relu, tanh, sigmoid} × auto 初始化。其中 relu/[256]/auto = E2 `arch256_seed{101,202,303}`（同配置已冻结存在，**直接复用不重跑**）；新增 tanh、sigmoid 共 6 次。
- **E7-B L2 复验（[256]，E4 协议）**：λ ∈ {0, 0.0001, 0.001}。λ=0 组 = E2 `arch256`（复用）；λ=0.0001 组与 E7-C 的 fixed_no_es 组为**同一配置**，只跑一次、两个 block 共同使用（设计性共享，非巧合）；新增 λ=0.0001、λ=0.001 共 6 次。
- **E7-C 策略复验（[256]，E5 协议，λ=0.0001）**：{fixed_no_es, fixed_es, step_no_es, step_es}（step：step_size=10，gamma=0.5；es：patience=5，min_delta=0.0001）。fixed_no_es 组即 E7-B λ=0.0001 组（共享）；新增 fixed_es、step_no_es、step_es 共 9 次。
- **E7-D 激活×初始化因子（[128]，E3 协议其余不变）**：{relu, tanh, sigmoid} × {he_normal, xavier_normal} 显式初始化，6 组合 × 3 seed = 18 次。注意：`auto` 是逐层混合策略（隐藏层按激活选 He/Xavier、输出层恒 Xavier），显式指定作用于全部层，故 6 个因子组合与 E3 的 3 组 auto 运行互不重复；E3 的 auto 组作为"对角线"参照一并报告。

5. 数学与实现约定

与 e4.md §5 完全一致：L2 目标 `J_obj = J_data + (λ/2)Σ‖W‖_F²`，仅惩罚权重；选型与报告指标一律为纯数据损失。当 λ=0 时 L2 项不得改变训练行为。

确定性校验（执行时强制）：
1. E7-B λ=0.0001 组与 E7-C fixed_no_es 组由同一批运行文件服务两个 block（磁盘上只有一份产物）。
2. E7-A/B/C/D 的验证集与 E1–E6 逐位相同（split_seed=2026，同一加载与切分代码）。
3. 若任何 run 出现 status != success，仅允许以"基础设施故障、留证据"为由同 seed 重跑一次并记录；不得改 seed 或改配置。

6. 结果与判定规则

主要指标：每组 3 seed 的 best_validation_loss 算术均值（完整精度），附总体标准差 ddof=0、best_validation_accuracy 均值±std、best_epoch。全部为 3 seed 描述性统计，**E7 内不做显著性声明**（推断检验由预注册 E8 承担，仅限其 4 个主对比）。

- Q1 判定（A/B/C 各自独立）：对 block 内各组按主指标排序，与对应 [128] 冻结结论（E3/E4/E5 报告表）比较。一致 = argmin 组相同；完全一致 = 全序也相同。逐项如实报告，不一致时**只描述不补救**（不得为"修复"排序追加运行或改网格）。
- Q2 判定（E7-D）：报告 2×3 因子表（行=初始化，列=激活）；分别给出"固定初始化下激活排序"与"固定激活下初始化排序"；与 E3 auto 对角线对照，描述激活主效应、初始化主效应与交互的相对大小（描述性）。
- 不以任何验证结果追加、删除或替换 block；不启动测试集评估。
